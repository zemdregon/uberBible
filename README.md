# uberBible

Public-domain Protestant Christian Bibles plus original-language texts (Hebrew OT, Greek NT/LXX, Coptic).

Catholic editions (Douay-Rheims, Vulgate, WEB Catholic, Petrus Canisius) and Jewish-specific translations (JPS, Leeser, Targum Onkelos) are excluded.

## Contents

| Path | Description |
|------|-------------|
| `source/ebible/` | 103 eBible public-domain translations (USFM) |
| `source/originals/` | Hebrew OT, Greek NT, and related source packages |
| `source/_meta/` | Catalog, download log, and index |

See [`source/_meta/INDEX.txt`](source/_meta/INDEX.txt) for the full translation list and package notes.

## Preferred format

USFM (easy to convert to Markdown).
